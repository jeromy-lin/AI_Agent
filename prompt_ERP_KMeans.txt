==================================================
【二、分析目的】
==================================================

本分析目的不是進行數值預測，
而是利用 ERP 中客戶歷史交易與報價行為，
建立 K-Means Customer Segmentation。

希望將具有相似交易行為的客戶自動聚集成群，
作為後續：

- 客戶經營
- 業務策略
- 報價策略
- 折扣管理
- 客戶風險管理
- 智慧看板
- AI Agent 決策支援

的資料基礎。

K-Means 的角色是回答：

「這一位客戶屬於哪一類？」

而不是直接替企業進行最終決策。

==================================================
【三、Customer-Level Feature Engineering】
==================================================

請將 ERP 原始交易資料整理成：

每一位客戶一筆資料。

建立以下 8 個客戶行為特徵：

1. 年化採購金額_TWD
2. 訂單次數
3. 平均訂單金額_TWD
4. 報價次數
5. 報價成交率
6. 平均折扣率
7. 平均預估毛利率
8. 最近交易天數

==================================================
【四、Feature 定義】
==================================================

--------------------------------------------------
1. 年化採購金額_TWD
--------------------------------------------------

先建立：

訂單金額_TWD
= 訂購數量 × 成交單價_TWD

再依每一位客戶加總：

總採購金額_TWD
= 所有訂單金額加總

ERP 資料期間約為 3 年，因此：

年化採購金額_TWD
= 總採購金額_TWD ÷ 3

--------------------------------------------------
2. 訂單次數
--------------------------------------------------

每位客戶的訂單筆數。

--------------------------------------------------
3. 平均訂單金額_TWD
--------------------------------------------------

每位客戶所有訂單金額的平均值。

--------------------------------------------------
4. 報價次數
--------------------------------------------------

每位客戶的歷史報價筆數。

--------------------------------------------------
5. 報價成交率
--------------------------------------------------

若「結果」欄位為：

成交

則視為成交成功。

計算：

報價成交率
= 成交報價次數 ÷ 報價次數

--------------------------------------------------
6. 平均折扣率
--------------------------------------------------

每位客戶所有歷史報價的平均折扣率。

例如原始資料：

0.065

表格顯示為：

6.50%

--------------------------------------------------
7. 平均預估毛利率
--------------------------------------------------

每位客戶歷史報價的平均預估毛利率。

例如：

0.25

表格顯示成：

25.00%

--------------------------------------------------
8. 最近交易天數
--------------------------------------------------

以 ERP 中最新的交易日期作為：

reference_date

計算：

最近交易天數
= reference_date - 最近一次下單日期

最近交易天數越大，
代表客戶越久沒有交易。

避免將企業人工分類的結果直接帶入演算法。

==================================================
【十一、客群命名原則】
==================================================

【VIP核心】

通常具有：

- 年化採購金額較高
- 訂單次數較高
- 報價互動較高
- 最近仍持續交易

代表高價值與穩定合作客戶。

--------------------------------------------------

【成長潛力】

通常：

- 採購規模不是最高
- 但仍有交易
- 成交率具有一定水準
- 有機會增加交易規模

代表可以進一步培養的客戶。

--------------------------------------------------

【價格敏感】

通常具有：

- 平均折扣率較高
- 平均預估毛利率相對較低

代表客戶對價格與折扣較敏感。

--------------------------------------------------

【沉睡／流失風險】

通常具有：

- 最近交易天數較高
- 訂單頻率較低
- 採購活躍度下降

代表需要重新喚回或追蹤。

==================================================
【十二、客群策略】
==================================================

建立以下策略：

VIP核心：

維持關係、優先服務、交叉銷售與長期合作。

成長潛力：

提高成交率、增加產品組合與業務接觸。

價格敏感：

管理折扣、檢查毛利、採差異化報價策略。

沉睡／流失風險：

優先喚回、追蹤未成交原因與近期需求。

legend(..., fontstyle="normal")

在輸出最終 Python Code 前，
請自行檢查整份程式是否能直接執行。

請確認：

1. 所有 import 都完整。

2. 不可有未定義變數。

3. 不可有 SyntaxError。

4. 不可有 TypeError。

5. 不可使用不存在的 Matplotlib 參數。

6. ax.legend() 不可使用：

fontstyle="normal"

7. plt.legend() 不可使用：

fontstyle="normal"

8. Legend 若需要正常字體，使用：

prop={"style": "normal"}

9. Customer Segment Profile 的 X 軸：

rotation = 0

10. Customer Segment Distribution 的 X 軸：

rotation = 0

11. 所有 Chart 英文文字不得斜體。

12. 四個客群結果必須真的產生四張 pandas Styler 表格。

13. VIP核心只能出現一張表。

14. 成長潛力只能出現一張表。

15. 價格敏感只能出現一張表。

16. 沉睡／流失風險只能出現一張表。

17. 客戶資料不可使用 print(DataFrame)。

18. 客戶資料不可使用 to_string()。

19. 不可產生所有欄位黏成一串文字的輸出。

20. 金額需有千分位。

21. 百分比顯示到小數第 2 位。

22. Table Header 必須保留。

23. DataFrame index 不顯示。

24. 不建立 Web。

25. 不使用 LLM API。

26. 不使用付費 API。

27. 不建立真正的 AI Agent。

28. 適合 Google Colab CPU 執行。

==================================================
【三十五、最終輸出要求】
==================================================

請一次完整輸出所有 Python Code。

請將完整程式放在一個 Python Code Block 中。

不要省略 import。

不要只輸出修改片段。

不要使用：

「以下省略」

「其餘相同」

「請自行補上」

「前面程式不變」

不要要求使用者自行拼接程式。

請在輸出前自行檢查：

- Excel Sheet 讀取
- 欄位名稱
- Customer_ID / 客戶ID 統一
- Data Cleaning
- Feature Engineering
- StandardScaler
- K-Means
- Silhouette Score
- Cluster Naming
- pandas Styler
- 四張客群表
- PCA
- Matplotlib Legend
- Customer Segment Distribution
- Customer Segment Profile
- rotation=0
- 所有變數定義

確認整段程式可以直接在 Google Colab CPU 環境由上到下一次執行後，
再輸出完整 Python Code。
