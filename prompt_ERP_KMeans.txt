【STEP 5｜Define K-Means Features】
==================================================

K-Means 使用以下 8 個 Feature：

FEATURES = [

    "年化採購金額_TWD",
    "訂單次數",
    "平均訂單金額_TWD",
    "報價次數",
    "報價成交率",
    "平均折扣率",
    "平均預估毛利率",
    "最近交易天數"

]

另外建立「K-Means 分群特徵」中文說明表：

年化採購金額_TWD
→ 客戶每年帶來的採購金額

訂單次數
→ 客戶下單頻率

平均訂單金額_TWD
→ 每張訂單的平均交易規模

報價次數
→ 業務與客戶之間的報價互動頻率

報價成交率
→ 報價轉換成訂單的比例

平均折扣率
→ 客戶平均取得的價格折扣

平均預估毛利率
→ 報價階段的平均預估毛利

最近交易天數
→ 距離最近一次交易的天數

並輸出說明：

「既有客戶等級（ERP）、產業別、銷售區域都不放入 K-Means。」

「K-Means 只根據 8 個實際交易／報價行為特徵進行無監督分群。」

「既有客戶等級（ERP）只在分群完成後用來對照，不參與分群計算。」

【STEP 8｜Cluster Profiling】
==================================================

根據標準化後的 Cluster Center
將四個 Cluster 轉換成以下商業名稱：

1. 高價值活躍型
2. 成長潛力型
3. 價格敏感型
4. 沉睡／流失風險型

命名邏輯：

【沉睡／流失風險型】

根據：

最近交易天數高
年化採購金額低
訂單次數低

建立 risk_score：

最近交易天數
- 0.5 × 年化採購金額
- 0.5 × 訂單次數

分數最高的 Cluster 定義為：

沉睡／流失風險型

【高價值活躍型】

根據：

年化採購金額高
訂單次數高
報價次數高
最近交易天數低

建立 score：

年化採購金額
+ 訂單次數
+ 報價次數
- 最近交易天數

剩餘 Cluster 中分數最高者定義為：

高價值活躍型

【價格敏感型】

建立：

平均折扣率
- 平均預估毛利率

剩餘 Cluster 中分數最高者定義為：

價格敏感型

最後剩餘 Cluster 定義為：

成長潛力型

建立欄位：

K-Means行為分群

群組順序固定：

1. 高價值活躍型
2. 成長潛力型
3. 價格敏感型
4. 沉睡／流失風險型
