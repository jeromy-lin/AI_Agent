要求：

5. 讀取工作表：

`SKU總表`

非常重要：

這份 Excel 的真正欄位名稱位於 Excel 第 3 列。

所以一定要使用：

```python
header=2
```

例如：

```python
product_df = pd.read_excel(
    file_name,
    sheet_name="SKU總表",
    header=2
)
```

讀取後，請清除欄位名稱前後空白：

```python
product_df.columns = (
    product_df.columns
    .astype(str)
    .str.strip()
)
```
